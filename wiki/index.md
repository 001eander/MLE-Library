## 概念

- [[cross-validation|交叉验证（Cross-Validation）：把分数当成估计量]] — 本库第一个「如何得到一个可信分数」的方法学类目，不引入新模型：CV 报出的是**一列折内分数**而非一个数；九族 splitter 不是九种写法而是五组关于「样本为何不独立」的假设（i.i.d. / 类比例 / 组独立 / 时间顺序 / 外部给定），因此选错不是噪声变大而是在回答另一个问题；三种调用式对应三种产品（`cross_val_score` 分数 / `cross_validate` 审计 / `cross_val_predict` 造折外特征，后者在 R² 上可与前者差 0.61）；分层是**会压小折间方差**的工程补丁（官方自己承认），而「折间 std → 标准误」的换算至今缺失；乐观偏差有两个来源（选择偏差、泄漏）且幅度是条件的（干净数据 +0.0000、噪声数据 +0.0500）；置换检验只能回答「是否优于随机猜测」（分辨率 = $1/(n_{\text{perm}}+1)$）。
- [[hyperparameter-search|超参数搜索（Hyperparameter Search）：把预算分配给候选]] — 本库第二个方法学类目（第一个是 [[cross-validation]]），回答「协议定完之后怎么搜」：搜索的五部件里只有两项属于搜索，其余三项都属于评估；三种工具是**三条预算曲线**（穷举按维数指数膨胀、采样把预算与维数解耦、逐次减半用资源递增换壁钟）；成本要按「拟合次数」记，而**逐次减半的拟合次数恒大于等于网格**（第一轮必须评估全部候选），它省的是样本量；`best_score_` 是 $m$ 个估计量的**最大值**而不是估计（dev/eval 实测偏差 +0.0067，嵌套 CV 的两个端点是 +0.0000 与 +0.0500）；「最好」在多指标与 callable `refit` 下需要被显式声明；失败分三档（部分 `nan` / 全部 `ValueError` / refit 永远抛错）；20 条失效模式。
- [[evaluation-metrics|评估指标与评分函数（Metrics and Scoring Functions）：先声明目标泛函，再选严格一致的评分]] — 本库第三个方法学类目，也是唯一一个**给「分数该是谁」下判据**的页：三层入口（估计器 `score` / `scoring=` / `metrics` 函数）返回不同的东西与符号；目标泛函（mean/median/quantile/mode）决定评分函数，严格一致性决定「能不能给同一侧的概率预报排序」（0-1 损失对众数只是 consistent，因此结构性地无法评价概率质量）；`scoring` 层的「越大越好」是 scorer 的私有 `_sign`，每个字符串名还绑定一个响应方法（`roc_auc` 的偏好序是 `decision_function`→`predict_proba`）；指标不匹配只会静默变 `nan`；决策阈值是模型外的第二步（实测同一模型四个阈值准确率 0.946/0.954/0.802/0.546）；以及「泛函错配反转排名」的六口径实测表（分位数模型在最差泛函上最优、在 $R^2$ 上为负），加 18 条失效模式。
- [[feature-preprocessing|特征预处理（Feature Preprocessing）：有状态变换、四个作用轴，以及「保秩/保相关/保稀疏」的三选]] — 本库第一个「改数而不删列、不换坐标」的概念页：把 16 个变换器按三个维度重排——`fit` 有没有学到状态（12:4）、作用在哪个轴（逐列/逐行/全矩阵/列之间）、保什么毁什么（分位数变换保秩但毁相关 Pearson 0.891→0.754、仿射缩放两者都保但对离群点不稳健、`MaxAbsScaler` 保稀疏但禁中心化）。给出五条可判定判据：缩放的合法性来自「下游假设里有没有同尺度这一条」（SVC 0.7767→0.9833）、序数编码的合法性来自「目标效应在字典序上是否单调」、目标编码的泄漏分三档（≤0.02 / +0.055 / +0.39）、「用列数买非线性」的四个档位（线性 0.6787 / 分箱 0.9552 / 多项式 0.9754 / 样条 0.9798）、以及 26 条失效模式。
- [[clustering|聚类（Clustering）]] — 本库第一个「无监督、输出标签」的类目：四条互不相同几何假设（inertia 的凸+各向同性、密度连通、图割、Ward 方差）、「$k$ 从哪来」的三种模式（显式 `n_clusters` / 阈值间接决定 / 算法自定）、归纳 vs 传导的硬断层（5 个估计器没有 `predict`）、以及指标的三个可判定性质（置换不变 / 机会校正 / 对称）——只有 ARI 与 AMI 能回答「比随机好多少」，只有对称指标能当共识度量，而三个内部指标（silhouette/CH/DB）都隐含凸簇假设、都不做机会校正。
- [[matrix-factorization|矩阵分解与成分分解（Matrix Factorization / Component Decomposition）]] — 本库第三个无监督产物：$X\approx UV$ 的同一骨架上，**约束就是模型**（PCA 正交/方差、TruncatedSVD 不中心化、SparsePCA 与 DictionaryLearning 的 $ℓ_1$、NMF 非负、FA 对角噪声、ICA 独立、LDA Dirichlet）；`components_` 第一次成为可读的一等输出，但方向/返回值每个模型都不同（PCA scores、NMF W、LDA 文档-主题）；可辨识性表（符号/旋转/排列/局部极小）解释了为什么「换种子结果变」是模型性质；以及「删列 / 换坐标 / 分组 / 分解」四种无监督产物的定位。
- [[covariance-estimation|协方差估计（Covariance Estimation）]] — 本库第一个**把估计量本身当研究对象**的类目：不预测、不分组、不降维，只估 $\Sigma$ 与 $K=\Sigma^{-1}$。四个收缩估计器是**同一个算子 + 三种 α 来源**（实测 LW/OAS 精确等于 `ShrunkCovariance(shrinkage=α̂)`）；「optimal」指 $\Sigma$ 的 MSE 而**不是**下游似然（实测 $p=5,n=40$ 时 α=0.1 的 NLL 7.267 优于 LW 的 7.295）；三个不同的收缩终点（$\frac{\mathrm{Tr}}{p}I$ / $I$ / 文档说的对角阵，后者在 1.6.1 上不成立）；`shrinkage='auto'` 对特征缩放**等变**而手设 float **不等变**（8.9e-15 vs 7.22）；$K$ 的 L1 学到的是**条件独立图**（$\Sigma$ 稀疏与 $K$ 稀疏是相反的事）；CV 的 α 使边数多 2.8–6.8 倍但 $\Sigma$ 误差最小——**四种损失口径系统性冲突**；以及 14 条失效模式。
- [[anomaly-detection|异常检测（Anomaly / Novelty / Outlier Detection）]] — 本库第一个「输出是『属不属于训练分布』而不是标签/坐标/成分」的类目：outlier vs novelty 的断层（训练集是否被污染 + 异常能否成簇）、四种形状假设（高斯椭圆 / 支持边界 / 隔离路径 / 局部密度比）、`score_samples → offset_ → ±1` 四段契约，以及**`offset_` 的四种默认语义**（IF 常数 −0.5、LOF 常数 −1.5、EE 数值 0.1、OCSVM 用 `nu`）——所以「同一数据上比较默认输出」不可比；另有两张实测表：密集异常簇的召回（LOF 0.03 vs IF/EE 1.00）与局部 vs 全局的排名（LOF 2/802 vs EE 802/802），以及尺度行为（IF 与 EE 完全不变、OCSVM 对单列缩放敏感、LOF 依赖度量）与 15 条失效模式。
- [[code-space-search|代码空间搜索与解树（Code-Space Search）]] — 解即程序、边即改进尝试；原子改动、`Σ(T)` 摘要、五种组织方式（含单链 keep/discard）的取舍与失败模式，含 AlphaEvolve 程序数据库、AIDE 解树与 autoresearch 单链的对照。
- [[tool-centric-research|工具中心的研究（Tool-Centric Research）]] — 把产出单位从「答案」换成「工具」：符号化/参数化载体、通用性阶梯与摊销式经济性。
- [[recursive-self-improvement|递归自我改进（RSI）]] — scaffold–data–model 闭环、四层循环及其失败模式、以瓶颈分类代替能力上限叙事。
- [[research-memory-tiers|研究记忆分层与知识成熟度分级]] — 项目状态／agent 记忆／跨任务 Books 三层，观察/已验证/约定三级，以及 skill 沉淀。
- [[experience-bank|经验库（Experience Bank）]] — 结构化记录 solution/日志/评分，并合成为多样化「灵感」的机制；含与 2.0 Books 的对照。
- [[evaluator-solution-co-evolution|评估器与解的共进化]] — 无现成评估器时的双层循环，以及 2.0 把外层折成独立复核与人工审批后的新瓶颈。
- [[leaderboard-vs-cv|排行榜与本地验证（Leaderboard vs CV）]] — 本地 CV / Public LB / Private LB 三套分数的分工；「信 CV」的前提是切分复刻真实划分结构；人类竞赛经验与 AIDE / autoresearch 的同一张力对照，并新增内置 CV（LOO 与 K 折）与 AIC/BIC 作为第三种代理指标来源。
- [[regularization-and-sparsity|正则化与稀疏性（Regularization and Sparsity）]] — 五种惩罚项的目标对照、软阈值与 ARD 两条稀疏来源、$ℓ_2$ 的贝叶斯读法、**七个正则化面**（协方差收缩 shrinkage/reg_param、平滑、SVM 的 `C`/margin、原型收缩 `shrink_threshold`、树容量 `ccp_alpha`、集成预算）在作用对象与“能否产生 0”上的对照（含样本维稀疏 vs 特征维稀疏）、MLP 的 `alpha` 作为同一 $ℓ_2$ 的矩阵版（只罚 `coefs_`、不罚偏置，不新增面）、AIC/BIC 的假设强度，以及「稀疏 ≠ 不重要」的三条边界。
- [[gaussian-discriminant-analysis|高斯判别分析（Gaussian Discriminant Analysis）]] — 生成式分类器：LDA ⊂ QDA 的假设嵌套、`GaussianNB` 作为对角特例与 `NearestCentroid` 作为 $\sigma^{2}I$ 极限（三者不是一条单链）、Mahalanobis 下的线性决策面、白化 + 对类均值做 PCA 的降维、参数个数随 $d$ 的二次增长与协方差收缩的动机。
- [[naive-bayes|朴素贝叶斯（Naive Bayes）]] — 条件独立买到的两个好处（$O(d)$ 参数、可增量）与代价（相关性不可见）；五个变体各自的分布假设与 4 个易读漏的点；「分类器好、估计量坏」派生出的五条用法受影响度；平滑 α 与 `var_smoothing` 作为第三个正则化面（与 shrinkage/reg_param 的区别）。
- [[support-vector-machines|支持向量机（Support Vector Machines）]] — 从几何出发而非损失/分布出发的第五个模型族；三层结构（最大间隔 → hinge → 对偶核技巧）、α 三态与**样本维稀疏（≠ 系数稀疏）**、C 与 ν 的两种刻度、四个输出面（分数/判决/概率/破平局）、按规模选实现的复杂度阶梯。
- [[nearest-neighbors|最近邻方法（Nearest Neighbors）]] — 本库第一个**零参数**模型族：模型就是训练集，于是「训练」只是建索引、「模型体积」等于数据体积；$k$（数量）与 $r$（体积）两种正则化方向、三种搜索结构（同一数学对象、三种代价、**选错只慢不错**）、预计算图作为可缓存中间产物、`NearestCentroid` 作为 LDA 的 $\sigma^{2}I$ 极限、NCA 作为「学一个度量」（$M=L^{T}L$）。
- [[decision-trees|决策树（Decision Trees）]] — 本库第七个模型族：分段常数 + 轴对齐递归划分的四个推论（查表式推理、不能外推、对单调变换免疫、矩形拼贴）；两级选择（候选切分 vs 判据 `criterion`）；贪心 + NP-complete 如何同时解释“不稳定”与“必须集成”；五个前剪枝旋钮与一个后剪枝 `ccp_alpha`（$R_\alpha(T)=R(T)+\alpha|\tilde T|$，罚的是**叶子数**）；缺失值三条预测规则中“训练未见 NaN → 走样本多的子节点”的隐性偏差；以及它“不需缩放 / 不能外推 / 原生缺失值”的独特位置。
- [[ensembles|集成方法（Ensembles）]] — 把多个模型拼起来的**两条轴**：平均式（bagging/RF/ET/voting/stacking，降方差、要求强模型）与顺序式（GBDT/HGBT/AdaBoost，降偏差、要求弱模型）；方差的 $\rho\sigma^2$ 下限如何解释「树多到临界点后不再变好」、GBDT 为什么是函数空间的梯度下降（$F_m=F_{m-1}+\nu h_m$、叶子值 $-\sum g/(\sum h+\lambda)$）、三个实现的代价模型、Stacking 为什么必须用折外预测、以及「正则化的三种机制：罚 / 删 / 平均」。
- [[feature-selection|特征选择（Feature Selection）]] — 本库第一个**「选择」类目**：删列而不是换坐标；三家族（过滤式/嵌入式/包裹式）的判据是「目标函数从哪来」与「是否迭代」，三者的盲点分别是不见冗余、继承模型偏好、继承 CV 方差；「选中集合」是 (数据, 模型, 超参) 的函数；代理指标的假设强度阶梯（F 检验 ⊂ χ² ⊂ 互信息，代价反过来）；「选多少」永远是超参且默认值都不中立；成本以「估计器拟合次数」计（`SelectFromModel` = 1，SFS = $O(kd\cdot\text{folds})$）；选择结果的方差在 API 里没有入口。
- [[multi-layer-perceptron|多层感知机（Multi-layer Perceptron, MLP）]] — 本库第一个**参数化、非凸、随机初始化**的模型族：隐藏层把「特征工程」换成「学表示」，`coefs_`/`intercepts_` 按层边界索引（长度 = `n_layers_ - 1`）、没有隐藏层时退化成线性输出；三个输出面（logistic/softmax/identity）与两种损失；三个求解器是三种训练契约（SGD/Adam 有 `partial_fit`，L-BFGS 没有）；`alpha` 是 $ℓ_2$ 的矩阵版且只罚 `coefs_`；非凸性如何变成种子方差与早停方差；与线性/SVM/KNN/树/集成的定位表；18 条失效模式。
- [[manifold-learning|流形学习（Manifold Learning）]] — 本库第一个**没有 $y$、输出是一套坐标**的类目：判别方法的第一性判据是**被保量**（测地距离/局部重构权重/图上邻近/内积/不相似度的序/邻域概率）；kNN 图是 Isomap/LLE/Spectral/t-SNE 的共同底座，因此「换缩放 = 换模型」；三阶段成本模型（邻居搜索 + 权重或图构造 + 特征分解）与两种失效方向（$k$ 太小→图不连通、太大→局部性被抹平）；LLE 的 `reg` 是**作用在邻域权重上的数值稳定器**而非第八个正则面；两个互补指标（`trustworthiness` 只罚假邻居、全局 Spearman）实测不一致（t-SNE 局部 0.9957 / 全局 0.6201 vs PCA 0.8538 / 0.6456）；以及「删列 vs 换坐标」的定位表与 10 条失效模式。
