# 支持向量机（Support Vector Machines）

本页整理 SVM 这一族的**结构性事实**：它为什么只依赖少数样本、`C` 与 `ν` 分别在约束什么、核技巧到底省掉了什么、以及为什么"分数"和"概率"是两个可分离的输出。事实来自 [[sklearn-svm]]，引用写作 `[[sklearn-svm]], L339`；凡是本库自己的推导或跨来源综合都显式标注。

## 家族坐标：SVM 与前四页的区别在哪

前四页的模型都从**损失**或**分布**出发；SVM 是唯一从**几何间隔 + 约束优化**出发的。

| 族 | 决策面的来源 | 参数代价 | 稀疏性出现在哪 | 本库页面 |
| --- | --- | --- | --- | --- |
| 判别式线性（Ridge/Logistic） | 损失 + 系数惩罚 | $O(d)$ | 特征维（仅 $ℓ_1$） | [[linear-models-as-baselines]] |
| 生成式判别分析（LDA/QDA） | 类条件高斯的对数比 | $O(d^2)$ / $O(Kd^2)$ | 无 | [[gaussian-discriminant-analysis]] |
| 朴素贝叶斯 | 类条件独立 + MAP | $O(Kd)$ | 无 | [[naive-bayes]] |
| **SVM** | **最大化间隔**（等价于最小化 $\lVert w\rVert^2$ + 松弛惩罚） | 支持向量个数 × $d$ | **样本维**（$\alpha_i=0$ 的样本被丢弃） | 本页 |
| 树/集成 | 轴对齐分段常数 | 模型相关 | 特征维（分裂用过与否） | 未入库（1.10/1.11） |

**本库综合**：最后两列的差别是实质性的。线性模型的稀疏在**特征**上，SVM 的稀疏在**样本**上——前者让模型可解释，后者让预测成本不随训练集线性增长。这个区别在 [[sklearn-svm]] 里被写在两处却从未并置（L216 与 L339），本页是第一次把两者对齐。

## 三层结构：几何 → 损失 → 对偶

SVM 的教学通常从几何讲起，但它的可计算性来自第三层。三层在同一条链上：

| 层 | 内容 | 关键公式 | 依据 |
| --- | --- | --- | --- |
| 几何 | 找间隔最大的超平面；间隔 = 到最近样本的距离 | 最大化间隔 ⇔ 最小化 $\lVert w\rVert^2$ | [[sklearn-svm]], L305、L323 |
| 损失 | 允许落在间隔内/错侧的样本，按距离线性计罚（hinge） | $\frac12 w^Tw + C\sum_i\max(0, 1-y_i(w^T\phi(x_i)+b))$ | L350（`LinearSVC` 形式）、L320（`SVC` 的 $\xi$ 形式） |
| 对偶 | 把约束问题转成只含**样本内积**的问题 → 可用核替换内积 | $\min_\alpha \frac12\alpha^TQ\alpha - e^T\alpha$，$0\le\alpha_i\le C$，$Q_{ij}=y_iy_jK(x_i,x_j)$ | L328、L331 |

### 为什么第二层是 hinge 而不是 0-1 或平方

来源只说"对误分类或落在间隔边界内的样本施加惩罚"（L323），并把 `squared_hinge`（`LinearSVC`）单独标出（L32）。

**本库综合**：hinge 的两个后果——(1) 超过间隔边界的样本**梯度为零**，所以它们对解完全没有影响，这就是支持向量稀疏的直接来源；(2) 它是**凸的但不可微**的分段线性函数，因此优化器只能用 QP/坐标下降而不是梯度法。`LinearSVC` 换成 `squared_hinge` 之后变可微，代价是**所有落在间隔内的样本都有非零梯度**，这也解释了为什么两个实现的 `support_` 不同（图 2 的图形旁证）——**这条是推断，来源未讨论**。

## 支持向量：α 的取值决定样本的三态

来源给出两个事实：对偶系数 $\alpha_i$ 上界为 `C`（L331、L323），且"其余样本的对偶系数 $\alpha_i$ 为零"（L339）。由此可得样本的三种状态：

| 状态 | $\alpha_i$ | 几何位置 | 是否进入决策函数 |
| --- | --- | --- | --- |
| 不在间隔内 | $0$ | 正确分类且在间隔外 | 否 |
| 间隔上的支持向量 | $(0, C)$ | 压在间隔边界上 | 是 |
| margin error | $C$ | 间隔边界错侧（含误分类） | 是 |

> [!note] 标注
> 三态分类是 KKT 条件的标准结论，但**来源没有逐条列出**。表中"是否进入决策函数"与"$\alpha_i=0$"来自 L339，"上界 $C$"来自 L331；三态与几何位置的对应是**本库据这两条推出的**（标为综合）。

`NuSVC` 提供的是同一结构的另一种刻度（回填，L358）：$\nu\in(0,1]$ 是 **margin error 比例的上界**、也是**支持向量比例的下界**，且与 `C` 参数化**数学等价**（L356）。来源给出的实践读法是"`nu` 近似训练误差与支持向量的比例"（L212）。

**本库综合**：ν 参数化的价值不在结果，而在**超参语义可解释**——你直接指定“我可以容忍多少比例的 margin error”，而不是在 $10^{-3}$–$10^{3}$ 的 `C` 网格上试。代价是 ν 与 `C` 不可同时设（互斥）；文档还说 `NuSVC` 少了 `class_weight`（L146），但 1.9.1 的实现接受该参数（外部核查，见 [[sklearn-svm]] 的分歧节）。

## 核技巧到底省掉了什么

四个内置核（L222–L225）：

| 核 | 形式 | 参数 |
| --- | --- | --- |
| linear | $\langle x,x'\rangle$ | — |
| polynomial | $(\gamma\langle x,x'\rangle + r)^d$ | `degree` ($d$)、`coef0` ($r$)、`gamma` ($\gamma$) |
| rbf | $\exp(-\gamma\lVert x-x'\rVert^2)$ | `gamma` > 0 |
| sigmoid | $\tanh(\gamma\langle x,x'\rangle + r)$ | `coef0`、`gamma` |

核技巧的实质：对偶问题里样本只以**内积**形式出现，所以把 $K(x_i,x_j)$ 换成一个隐式特征映射 $\phi$ 的内积，就能在**不显式计算 $\phi(x)$** 的情况下在高维空间里做线性分类（L331）。来源的表述是"训练向量被 $\phi$ 隐式映射到更高（可能无限）维空间"，并指向 kernel trick 条目（L331）；它推荐的深入读物是 [13]（Bishop ch.7）与 [14]（Smola & Schölkopf）（L311）。

自定义核的两条契约（L253–L297）：

| 方式 | 接口 | 代价 |
| --- | --- | --- |
| Python 函数 | $f$ 吃 `(n1, d)`、`(n2, d)` 两个矩阵，返回 `(n1, n2)` 核矩阵（L264） | 每次求值都走 Python → 慢 |
| `kernel='precomputed'` | 自己传 Gram 矩阵；**所有**训练×测试核值都要提供（L279） | 内存 $O(n^2)$；但能在 C 层批量化 |

两个副作用（L255–L258）：`support_vectors_` **为空**（只剩索引 `support_`）；`fit()` 的第一个参数存的是**引用**，之后改动该数组会让 `predict` 结果异常。

**本库综合**：第二条副作用意味着**自定义核下模型不可审计**——你既没有支持向量副本，也没有训练集快照。工程上应把 Gram 矩阵当作不可变对象传给 `fit`。

## 一个分类器的四个输出面

这是本节最容易被忽略、但对接评估指标最关键的部分。同一模型有四个不同层级的输出：

| 层 | 方法／参数 | 含义 | 一致性保证 |
| --- | --- | --- | --- |
| 原始分数 | `decision_function` | 到超平面的带符号距离（多类为每类一个） | — |
| 判决 | `predict` | 类标签 | 多类 ovr 下**默认不破平局**（返回第一个并列类，L140） |
| 校准概率 | `predict_proba`（需 `probability=True`） | Platt 校准后的类概率 | **与分数的 argmax 可能不一致**（L135–L136） |
| 破平局后的判决 | `break_ties=True` | 等于 `np.argmax(decision_function(...), axis=1)` | 有额外算力成本（L140） |

来源对此的结论很直接：**只要置信分数、不需要概率，就关掉概率并直接用 `decision_function`**（L138）；概率校准要跑内部交叉验证，在大数据上昂贵（L133）。

**本库综合（跨来源）**：[[sklearn-naive-bayes]] 说 NB "is known to be a bad estimator"（概率不可信），但没给修法；本节给了修法（Platt）**同时**说明修法本身也不保序。两条合起来得到一个可操作的判据：**评估指标该在哪一层算，由下游用途决定**——排序/阈值用 `decision_function`，期望收益用校准概率，报告准确率用 `predict`（且要指定 tie 规则）。这条对 [[leaderboard-vs-cv]] 的指标选择与 [[evaluator-design-and-reward-hacking]] 里的"把概率当分数"直接相关。

## C 是逆正则强度，且只对 Ridge 有闭式换算

`C` 控制松弛惩罚的权重，来源因此称它为**逆正则化参数**（L323）。跨模型换算只有一条（L344）：

$$C = \frac{1}{\alpha}\quad(\text{对 Ridge 回归})$$

来源同时声明"精确的等价关系取决于各自优化的目标函数"，即**对其他估计器没有通用换算式**。

**本库综合**：这与 [[regularization-and-sparsity]] 的"跨估计器 `alpha` 不可比"是同一结论的正反两面。工程上的含义是：**把 `C` 与 `alpha` 放进同一个搜索空间是错的**；要么各自重扫，要么只用 `C = 1/α` 这一条把 Ridge 与 SVC 对齐（且只对线性核有意义）。

还有一层耦合（L146、L150）：`class_weight` 与 `sample_weight` 都是**把该样本/类别的 `C` 乘一个系数**，所以加权之后有效正则强度变了，必须重扫 `C`。

## 复杂度：为什么这个族要按规模选实现

| 实现 | 求解器 | 复杂度 | 适用 |
| --- | --- | --- | --- |
| `SVC`/`NuSVC`/`SVR`/`NuSVR` | libsvm（QP + 缓存） | $O(n_f n_s^2)$ – $O(n_f n_s^3)$（依缓存命中） | 中小样本、非线性核 |
| `LinearSVC`/`LinearSVR` | liblinear（坐标下降） | 近线性，"millions of samples and/or features" | 大样本、只要线性核 |
| `SGDClassifier(loss='hinge')` | SGD | 单遍/多遍线性 | 流式、超大且不想拷贝数据 |

依据：L192（前两行）、L194（liblinear）、L199（拷贝问题时官方建议换 `SGDClassifier`）。稀疏数据时把 $n_f$ 换成**平均非零特征数**（L192）。

**本库综合**：这三行构成一条**规模阶梯**，不是精度阶梯。$n_s$ 到 $10^5$ 时核方法仍可行（缓存调大，L200），到 $10^6$ 只有后两行可行。这条判据在本库是首次出现——前四页的模型都没有规模上界问题（线性模型是 $O(np^2)$，NB/LDA 是闭式）。

## 回归一侧：ε 管与两个对偶系数

ε-SVR（L362–L384）把"错侧的间隔"换成"$\pm\epsilon$ 的容忍带"：预测与目标的偏差小于 $\epsilon$ 时不计罚（L392 的 ε-insensitive loss、L368 的 "$\epsilon$ tube"）。预测式为

$$\sum_{i\in SV}(\alpha_i-\alpha_i^*)K(x_i,x)+b$$

属性 `dual_coef_` 存的是**差值** $\alpha_i-\alpha_i^*$（L384），而分类里存的是乘积 $y_i\alpha_i$（L341）。

**本库综合**：这条差异意味着**两个任务的 `dual_coef_` 不可同读**。分类的符号编码类别，回归的符号编码"预测偏高还是偏低"。要做特征重要性或样本影响分析，必须按任务分别解读。

`LinearSVR` 与 `LinearSVC` 同源（liblinear），因此**同样正则化截距**（L165），并同样有 `intercept_scaling`；来源在此处保留了从分类节照抄的措辞——说 `LinearSVR` 的结果"可能与另外两个（分类器）不同"（L165），属措辞漏改。

## 失效模式

| 失效 | 表现 | 依据 |
| --- | --- | --- |
| 未缩放特征 | 分数明显变差，但**不报错** | L203（"not scale invariant"） |
| 训练/推理稀疏性不一致 | 走慢路径，可能极慢 | L24（"must have been fit on such data"） |
| 高维低样本时调参过拟合 | CV 分数虚高 | L21（选核与正则强度是过拟合的地方） |
| 概率当作可信度 | `predict` 与 `predict_proba` 冲突 | L135–L136 |
| 多类 ovr 平局 | 结果依赖类顺序 | L140（默认不破平局） |
| 大 `C` | 训练时间可长 10 倍，收益停止 | L202 |
| 自定义核下原数组被改动 | 预测结果异常且难定位 | L258（存引用） |

## 待解问题

- **hinge 的"零梯度区"与 `squared_hinge` 的差异能否量化？** 本页称它是图 2 中支持向量分布不同的原因，但这是推断，未做实验（[[sklearn-svm]] 待解问题 6 相关）。
- **$O(n_f n_s^2)$ 与 $O(n_f n_s^3)$ 之间的实际位置由什么决定？** 来源只说"取决于缓存用得多有效"。若能给出"$n_s$ / `cache_size`"的经验阈值，规模判据就能变成数字。
- **ν 与 C 的等价映射能否解析给出？** 来源说"数学等价"（L356），但没给换算式；若能给出，就能把两个实现的网格互相复用。
- **`dual_coef_` 能否作为多类样本重要性的可靠来源？** 本页判断"不能"，但没找到替代方案的来源。
- **校准后的概率保序性有多差？** 来源只给"argmax 可能不一致"（L135），没给发生率。这是一个可以用合成数据测量的问题。
- 核近似（`sklearn.kernel_approximation`，L238 指向但未入库）与真核的差距在什么规模上可接受？本库无来源。
