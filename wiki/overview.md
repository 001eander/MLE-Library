# MLE Library

A personal Machine Learning Engineering knowledge base maintained by a Pi librarian under human supervision.

## Purpose

- Learn new Machine Learning Engineering concepts and revisit practical guidance.
- Give the MLE AutoResearch Agent read-only access to curated knowledge and source evidence.

## Layers

- `raw/` contains immutable source material. PDFs, clipped articles, and original assets are never edited in place.
- `wiki/` contains librarian-maintained Markdown pages. Important claims link back to source pages and precise source locations.
- `AGENTS.md` and `skills/` define how the librarian ingests, queries, maintains, and commits knowledge.

## Reading paths

Start with [[index]]. Topic pages live in `concepts/`, engineering guidance in `practices/`, tool-specific notes in `tools/`, and source summaries in `sources/`. Draft research remains in `research/` until a person decides to promote it into stable knowledge.

The library currently contains no ingested sources. Its scope will grow with the material and questions added by its owner.
